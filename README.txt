CINEMATIC PROPOSAL PORTFOLIO

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Replace images/photo1.jpg to photo4.jpg with your own photos.
4. For music, put an MP3 in music/ and rename it song.mp3.
5. Open index.html with Live Server.

The site is a cinematic, full-screen story with chapters, photo zoom,
music button, proposal reveal and final ending.
